# Changelog

All notable changes follow [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and this project uses semantic versioning.

## [0.1.1] - 2026-09-05

### Added

- A bundled three-file demo command and an isolated browser demo.
- Claim, copy, route, response-header, release-cache, and installer regression checks.

### Fixed

- Azure Static Web Apps now applies CSP, Permissions-Policy, no-referrer, and immutable hashed-asset caching.
- The website caches successful GitHub release details locally for one hour.

## [0.1.0] - 2026-08-28

### Added

- Manifest-driven deterministic batch exports with safe direct converter invocation.
- Validation, concurrent execution, normalized names, Linux sandbox option, and JSON reports.
- Cross-platform installers, package metadata, release automation, and blueprint documentation site.
