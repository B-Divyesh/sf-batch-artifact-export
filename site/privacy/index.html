How Batch Artifact Export handles data

Effective September 5, 2026.

The CLI

Batch Artifact Export processes source files on your device. It sends no product telemetry and has no account system.

It runs only the local converter commands you declare. Those independent tools have their own privacy behavior.

This website

This static site sets no cookies and stores no personal data.

The manifest check does not save or transmit what you paste. Demo changes stay in the current page and are discarded when you leave it.

The page requests public release details from GitHub. It caches those details in local storage for one hour.

GitHub receives the connection data needed for that request under its own privacy policy.

Remove stored release details

Clear this site's browser storage to remove the cached public release details. The cache expires after one hour.
