Privacy, by absence.

Effective August 28, 2026.

The CLI

Batch Artifact Export processes source files on your device. It contains no telemetry, analytics, account system, network client, or automatic update checker. It invokes only the local converter commands you declare. Those independent tools have their own privacy behavior.

This website

This static site sets no cookies and stores no personal data. The manifest inspector runs entirely in your browser and does not save or transmit what you paste. To show the current download, the page requests a release manifest from GitHub; GitHub receives the ordinary connection metadata involved in that request under its own privacy policy.

Contact

Report privacy concerns through the public repository issue tracker.
